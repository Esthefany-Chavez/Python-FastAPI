# Fundamentos de Python: Estructuras de Control y Funciones

## Descripción

Este proyecto reúne la solución de tres retos propuestos en la actividad **Fundamentos de Python: estructuras de control y funciones**. Cada reto está organizado en una carpeta según la estructura solicitada y cuenta con comentarios para facilitar su comprensión.

## Estructura del proyecto

Se que la estructura propuesta que usted me dio fue la siguiente:

```
fundamentos_python_control_fun/
│
├── README.md
│
└── src/
    ├── condicionales/
    │   └── reto01.py
    │
    ├── iterativas/
    │   └── reto02.py
    │
    └── funciones/
        └── reto03.py
```
Pero mirando y comprendiendo cada reto y la estructura que utilizada para cada uno me tome la libertad de estructurarlos de la siguiente manera para que cada reto estuviera en la carpeta a al que senti que correspondía.

```
fundamentos_python_control_fun/
│
├── README.md
│
└── src/
    ├── condicionales/
    │   └── reto02.py
    │
    ├── iterativas/
    │   └── reto03.py
    │
    └── funciones/
        └── reto01.py
```

## Requisitos

- Python 3.x instalado.
- Editor de código como Visual Studio Code, PyCharm o similar.

## Cómo ejecutar cada ejercicio

### Reto 1 - Calculadora de Métricas del Desarrollador

Ubicación:

```
src/condicionales/reto02.py
```

Ejecutar desde la carpeta principal del proyecto:

```python
python src/condicionales/ py reto01.py
```

El programa solicitará:
- Nombre del desarrollador.
- Cantidad de proyectos asignados.
- Horas dedicadas a cada proyecto.

Al finalizar mostrará un reporte con:
- Total de horas trabajadas.
- Promedio de horas por proyecto.
- Porcentaje de tiempo dedicado a cada proyecto.

---

### Reto 2 - Sistema Simplificado de Calificación e Inventario

Ubicación:

```
src/iterativas/reto03.py
```

Ejecutar:

```python
python src/iterativas/py reto03.py
```

El programa utiliza una lista de stock predefinida y muestra:
- Estado de cada producto.
- Lista de productos agotados.
- Lista de productos con stock crítico.
- Porcentaje general de disponibilidad del inventario.

---

### Reto 3 - Motor de Análisis de Frecuencia de Texto

Ubicación:

```
src/funciones/reto01.py
```

Ejecutar:

```python
python src/funciones/py reto03.py
```

El programa solicitará una frase o un párrafo, luego:
- Convertirá el texto a minúsculas.
- Eliminará signos de puntuación básicos.
- Contará la frecuencia de cada palabra.
- Mostrará la palabra con mayor frecuencia y su cantidad de apariciones.
