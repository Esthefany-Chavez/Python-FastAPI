# 🐍 Python y FastAPI - ADSO SENA

Repositorio donde se recopilan las actividades, prácticas y proyectos desarrollados durante el proceso de formación en **Python y FastAPI** del programa **Tecnología en Análisis y Desarrollo de Software (ADSO)** del **SENA**.

---

## 📖 Descripción

Este repositorio funciona como un portafolio de aprendizaje en el que se documentan los ejercicios y proyectos realizados durante la formación.

Cada actividad se encuentra organizada en una carpeta independiente con su respectivo **README.md**, donde se describe el proyecto, los temas trabajados y la forma de ejecutarlo.

---

## 🎯 Objetivo

- Documentar el proceso de aprendizaje.
- Organizar las actividades desarrolladas durante la formación.
- Aplicar buenas prácticas de programación y documentación.
- Construir un portafolio de proyectos realizados en Python y FastAPI.

---

## 📚 Temáticas generales

Durante la formación se abordan temas como:

- Fundamentos de Python.
- Estructuras de control y funciones.
- Programación Orientada a Objetos.
- Estructuras de datos.
- Desarrollo de APIs con FastAPI.
- Integración con bases de datos.
- Desarrollo de proyectos prácticos.

---

## 📂 Organización del repositorio

Los proyectos se encuentran organizados en carpetas independientes. Cada una incluye su propia documentación, ejemplos y evidencias, permitiendo mantener el repositorio ordenado y facilitar su consulta.
